# 星語 Xingyu

結合紫微斗數、塔羅牌與 AI 語意解讀的繁體中文網站，保留深靛色與霧金色的線條星空美術。

- 十二宮本命盘、便利的出生日期輸入與時辰提示。
- 78 張塔羅牌，三張不重複的牌與正逆位線稿。
- 分析完整問題與補充背景，可沿用同一組牌／命盤追問四次。
- 失敗可重試且保留抽牌，不以模板代替 AI 回應。
- 收藏完整對話與下載；舊收藏明確標為舊版牌義紀錄。

AI 必須連接可用的 Vercel AI Gateway 後端與額度。部署及驗證見 [AI-SETUP.md](AI-SETUP.md)。GitHub Pages 提供前端，後端部署在 Vercel；金鑰不可放入前端或公開儲存庫。

## 維護

執行 npm install、npm test、npm run build、npm run preview。靜態預覽在 http://127.0.0.1:4320，不會生成真實 AI 解讀。修改原始碼後建置，並提交產生的 app.js。Vercel 靜態輸出僅複製網站檔案至 public/。

## 隱私與範圍

命盤在瀏覽器計算；同意後將問題、補充情況、宮位星曜、牌面及追問文字傳送給 Vercel AI Gateway 與模型供應商。出生日期、出生地與性別不會傳送。請勿輸入姓名、聯絡方式或敏感資訊。收藏保留在本機瀏覽器，最多 30 筆；清除瀏覽器資料會清除收藏。

象徵解讀供自我探索，不能證明他人想法或確定預告事件。紫微使用本命星曜與四化，未計算流年、真太陽時或時區校正。
