# 星語 Xingyu

結合紫微斗數、塔羅牌與 ChatGPT 分析的繁體中文網站，保留深靛色與霧金色的線條星空美術。

目前採不呼叫 API 的轉接方式：使用者提問、填補充背景、排盤／抽牌後，複製完整分析資料，開啟自己的 ChatGPT 貼上。分析與追問在 ChatGPT 進行；網站不會自動取得回答，也不會替使用者支付 API 費用。ChatGPT 可用功能與用量依使用者帳號而定。

- 十二宮本命盤、便利的出生日期輸入與時辰提示。
- 78 張塔羅牌，三張不重複的牌與正逆位線稿。
- 完整問題、背景、實際星曜與牌面整理；引導 ChatGPT 做具體分析。
- 收藏問題、命盤與牌面。既有舊版解讀明確標示為舊版牌義紀錄。

## 維護

執行 npm install、npm test、npm run build、npm run preview。靜態預覽網址：`http://127.0.0.1:4320`。修改原始碼後建置，並提交產生的 app.js。GitHub Pages 從 main 的根目錄發布。

site-config.js 的 analysisMode 預設為 chatgpt。gptUrl 留空時開啟一般 ChatGPT；未來可設定自訂 GPT 的分享網址。API 模式程式保留供後續使用，目前不啟用；部署條件見 AI-SETUP.md。

## 隱私與範圍

命盤計算與分析資料整理都在瀏覽器完成，沒有自動傳送內容。使用者自行複製並貼到 ChatGPT 後，資料才由 ChatGPT 處理。分析資料包含問題、補充情況、宮位星曜與牌面；排除出生日期、出生地及排盤性別。請勿在問題中輸入姓名、聯絡方式或敏感資訊。收藏保留在本機瀏覽器，最多 30 筆。

占卜象徵不能證明他人想法或確定預告事件。紫微使用本命星曜與四化，未計算流年、真太陽時或時區校正。
